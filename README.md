# 사무툴 (Samu Tools)

**https://davpoqn.github.io/samu-tools/**

자주 쓰는 사무 작업을 브라우저에서 바로 처리하는 단일 HTML 도구 모음입니다.
설치도, 서버도, 계정도 필요 없습니다. **파일은 PC(브라우저) 밖으로 나가지 않습니다.**

https://davpoqn.github.io/samu-tools/

## 들어 있는 도구

| 파일 | 이름 | 하는 일 |
|---|---|---|
| `index.html` | 사무툴 (허브) | 세 도구로 가는 메뉴 |
| `extract.html` | 파일 형식 추출 | 폴더나 ZIP을 넣으면 파일 종류별 개수·용량을 세어 보여주고, 고른 형식만 한 폴더로 모읍니다 |
| `rename.html` | 파일 이름 정리 | 번호 매기기·찾아 바꾸기·폴더명 붙이기로 이름을 일괄 변경. 바뀔 이름을 먼저 보여주고 되돌릴 수 있습니다 |
| `excel.html` | 엑셀 수식 오류 진단 | `.xlsx`에서 `#N/A` `#REF!` `#DIV/0!` 등이 난 셀을 찾아 원인까지 짚어 줍니다. 같은 열에서 범위가 어긋난 셀도 잡아냅니다 |

## 쓰는 조건

- **Chrome 또는 Edge** (최신). 폴더를 직접 읽고 이름을 바꾸는 기능은 File System Access API를 씁니다.
- Safari·Firefox·모바일 브라우저에서는 폴더 선택 기능이 동작하지 않습니다. `extract.html`의 ZIP 다운로드만 어디서나 됩니다.
- 처음 폴더를 고를 때 브라우저가 권한을 한 번 물어봅니다.

## 각 도구의 한계

**파일 형식 추출 / 파일 이름 정리**
- 파일 내용은 읽지 않습니다. 이름과 목록만 다룹니다.
- 되돌리기 기록은 창을 닫으면 사라집니다. 큰 작업은 적용 직후 확인하세요.
- 이름이 겹치거나 쓸 수 없는 글자가 있으면 그 항목은 적용에서 자동으로 빠집니다.

**엑셀 수식 오류 진단**
- `.xlsx` / `.xlsm`만 됩니다. 옛 `.xls`는 엑셀에서 "다른 이름으로 저장 → xlsx"로 바꿔 주세요.
- 계산을 다시 하지 않고 **파일에 마지막으로 저장된 계산 결과**를 읽습니다. 그래서 엑셀 화면에서 본 값과 같지만, 수식을 고치고 저장하지 않은 파일은 반영되지 않습니다.
- 매크로는 실행하지 않습니다(수식만 읽습니다).
- 병합 셀, 복잡한 배열 수식은 진단이 뭉뚱그려질 수 있습니다.

## 개인정보

모든 처리는 브라우저 안에서만 이루어집니다. 파일이 서버로 업로드되지 않습니다.
이 저장소에는 어떤 파일도 수집·전송하는 코드가 없습니다.
